Milestone 1 "Shell and viewport"

State: In progress: approved 2026-10-27. Steps 1 and 2 checked. Step 3 (main window) is ready to test.

Read this first
  • Goal: a Quadra window that looks like mockup A, shows four working viewports that stay at 60 FPS with 10 million triangles, lets you create, select and move objects with Max's shortcuts, undo anything, and save and load USD.
  • First step is the viewport prototype. If wgpu cannot reach 60 FPS at 10M triangles, Claude stops and brings options before building anything else.
  • Out of scope: the modifier stack and Poly Edit (M2), materials and rendering (M3), animation (M4), scripting (M5). The time slider and track bar are drawn but do nothing yet.
  • You check every step as it lands. Each step's test is in section 3.
  • To change anything, write in the notes box under it, press Copy my notes, and paste to Claude.

1. Parts

  • Project setup: its own git repo, Cargo workspace, licence file, README with a Disclaimer section, Main Run and Dev Run configs.
  • Viewport prototype: a bare wgpu window that draws a generated 10M-triangle scene (1,000 objects, 10% instanced) and logs frame times, so we measure before we build.
  • Main window: the mockup A layout in egui with docking: menu bar, toolbar, Scene Explorer, command panel, time slider, track bar, status bar. Correct at 100% to 200% Windows scaling.
  • Four viewports: Top, Front, Left, Perspective; wireframe and shaded modes; grid; our own view cube; orbit, pan, zoom, maximise.
  • Create panel: standard primitives, lights, cameras and helpers, made by dragging in a viewport.
  • Select and transform: click and box select, Scene Explorer selection, move, rotate and scale gizmos, snaps.
  • Shortcuts and settings: the M1 rows of keymap.json, rebindable in the app; a settings page where every change applies at once and is saved.
  • Undo: every edit goes through the command bus; unlimited undo and redo.
  • Files: save and load the scene as USD.
  • About and updates: About page with every third-party licence and the disclaimer; check GitHub releases for updates at start-up.

3. How to test each step

Step 1: project setup (checked by doole 2026-10-27)

  1. Open a terminal in E:\REPOS\3D TOOLS\Quadra.
  2. Type cargo run -p quadra_app and press Enter.
  3. You should see Quadra 0.1.0 and a one-line licence notice. No window opens yet.
  4. Open the folder in IntelliJ. The run list shows exactly two configs: Main Run and Dev Run. Dev Run prints the same two lines. Main Run works once the first commit is on main.

Step 2: viewport prototype

  1. In the same terminal, type cargo run --release -p quadra_vp_proto and press Enter. The first build takes a few minutes.
  2. A window opens behind your other windows. Click it in the taskbar. You should see about 1,000 coloured bumpy balls with the camera slowly circling them.
  3. The terminal prints one line a second. The FPS number should be well above 60. Claude's run on 2026-10-27: about 1,660 FPS (0.6 ms a frame, worst 12 ms) on the RTX 5070 Ti.
  4. Close the window. The last line is a summary of the whole run.

This is a best case: one simple shader and one view. The real viewport adds four views, the UI and wireframe, so expect a fraction of this, still far above 60.

Step 3: main window

  1. Type cargo run --release -p quadra_app and press Enter. The Quadra window opens behind your other windows; click it in the taskbar.
  2. Put it next to docs/mockups/a-familiar.html. Menu bar, toolbar, Scene Explorer on the left, four views in the middle, Command Panel on the right, time slider, track bar and status bar should all sit in the same places with the same colours. The ribbon row is left out: it is not in M1.
  3. Click the Move, Rotate and Scale buttons: the blue highlight follows. Click a view: the gold border moves to it.
  4. Drag the "Command Panel" tab onto the left edge of the window: it docks there. Drag it back.
  5. Help > About Quadra shows the licence notice. File > Exit closes the window.
  6. Menus and buttons for later steps are greyed out or say which milestone fills them. The views stay empty until step 4.

4. Review checklist (at the end of M1)

  • Open the 10M-triangle test scene and orbit: the frame counter stays at 60 or more.
  • Start Quadra from cold: the viewport accepts input within 3 seconds.
  • Put mockup A and Quadra side by side: same layout and colours.
  • Create a box, sphere, light and camera; select, move, rotate and scale them using Max shortcuts.
  • Undo everything back to the empty scene, then redo it all.
  • Save as USD, close, reopen: the scene is the same.
  • Change a shortcut and a setting: both work at once and are still there after a restart.
